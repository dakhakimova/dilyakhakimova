    Занятие 5 · блок 4

    Дельта-метод, линеаризация, бакеты

    Три способа честно посчитать SE для ratio-метрики. Все три работают на уровне пользователя и дают почти одно и то же — выбирают по удобству в платформе.

    Определение

    Дельта-метод для отношения

    R=Yˉ/Xˉ — отношение средних по n пользователям; μX​,μY​ — их ожидания.

    1. Линейное приближение. Ряд Тейлора первого порядка для f(x,y)=y/x около (μX​,μY​); ∂f/∂y=1/μX​, ∂f/∂x=−μY​/μX2​:

      R≈μX​μY​​+μX​1​(Yˉ−μY​)−μX2​μY​​(Xˉ−μX​).

    2. Дисперсия линейной комбинации aYˉ+bXˉ равна (a2σY2​+2abcov(X,Y)+b2σX2​)/n. С a=1/μX​, b=−μY​/μX2​:

      Var(R)≈n1​(μX2​σY2​​−μX3​2μY​cov(X,Y)​+μX4​μY2​σX2​​).

    3. Дальше как в занятии 4. Все величины — по пользователям. SEΔ​=Var(RA​)+Var(RB​)​, z=Δ/SEΔ​.
    Задача

    Задача 5. Дельта-метод для CTR

    В группе 10 000 пользователей. Показов на пользователя в среднем 20, дисперсия 400; кликов — 2, дисперсия 9; ковариация кликов и показов — 50. Посчитай CTR и его SE дельта-методом. Сравни с «наивной» SE, если считать 200 000 показов независимыми.

    Решение

    Шаг 1. R=2/20=10%.

    Шаг 2. Слагаемые. σY2​/μX2​=9/400=0.0225; 2μY​cov/μX3​=2⋅2⋅50/8000=0.025; μY2​σX2​/μX4​=4⋅400/160000=0.01.

    Шаг 3. VarR≈(0.0225−0.025+0.01)/10000=7.5⋅10−7, SE≈0.000866, то есть 0.087%.

    Шаг 4. Наивная. По 200 000 показам: 0.1⋅0.9/200000​≈0.067% — на четверть меньше, и z был бы завышен в 1.3 раза.

    CTR 10%, SE дельта-методом ≈ 0.087%, наивная ≈ 0.067% — занижена на четверть.

    Определение

    Линеаризация и бакеты

    1. Линеаризация. Для каждого пользователя Li​=Yi​−R^A​Xi​, где R^A​ — отношение в контроле. Средняя L в контроле — ноль, в тесте — YˉB​−R^A​XˉB​. Сравниваем L обычным t⁠-⁠тестом по пользователям. Это та же формула дельта-метода, записанная как метрика пользователя; удобно, когда платформа умеет только t⁠-⁠тест или CUPED.
    2. Бакеты. Пользователей группы хешем делят на B бакетов — ориентир сотня, — в каждом считают ∑Y/∑X и сравнивают группы t⁠-⁠тестом по бакетам. Бакеты независимы, их отношения по ЦПТ почти нормальны. Хранят по бакету суммы числителя и знаменателя, а не готовое отношение.
    Итог блока

    Три честных способа

    Для ratio-метрики SE считают по пользователям: дельта-метод, линеаризация L=Y−R^A​X с t⁠-⁠тестом или бакеты. Все три держат α; t⁠-⁠тест по событиям — нет.
