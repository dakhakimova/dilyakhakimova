Как монетка может помнить гостя?

Боб, продакт

Ладно, монетку бросаем один раз на гостя. Но где приложение хранит, кому что выпало? Это же миллионы записей.

Алиса, аналитик

Нигде. Оно каждый раз вычисляет группу заново — из номера гостя.

Боб, продакт

Тогда просто по номеру: до середины — старое приложение, дальше — новое?

Алиса, аналитик

Нет: номера выдают по порядку, маленькие — у давних гостей. Нужна мясорубка, которая перемешает номера.

Котейка

Мяу. Мясорубку для текста я покручу. Клади туда номер гостя и название эксперимента.

Что здесь происходит

У каждого гостя в приложении есть постоянный номер — id, например user_48213. Хеш-функция — мясорубка для текста: из одного и того же текста всегда выходит одно и то же число, а из чуть другого — совсем другое.

Приложение склеивает id с названием эксперимента, пропускает через хеш и берёт остаток от деления на 100 — номер ячейки от 0 до 99. Ячейки 0–49 — старый экран, 50–99 — новая кнопка. Меняй id и эксперимент и смотри, куда попадает гость.

Игрушка не загрузилась? Открой её в курсе.

Попробуй

  1. Нажми «Соседний id» несколько раз. Соседние номера попадают в соседние ячейки?
  2. Впиши обратно user_48213. Ячейка та же, что была?
  3. Нажми «Другой эксперимент»: тот же гость, другое название. Ячейка осталась прежней?

Что получилось

Вывод откроется, когда покрутишь игрушку.

Соседние id, которые отличаются одной цифрой, разлетаются по ячейкам как попало: user_48213 — в ячейку 17, user_48214 — в 84, user_48215 — в 3. Но один и тот же id в том же эксперименте всегда даёт одну и ту же ячейку: монетку не нужно хранить, её результат вычисляется заново. А в другом эксперименте у того же гостя совсем другая ячейка.

Шпаргалка

  • хеш(id + название эксперимента) → остаток от деления на 100 → ячейка → группа.
  • Тот же текст — та же ячейка: гость не прыгает между группами.
  • Соседние id разлетаются случайно, поэтому давние и новые гости перемешаны.
  • Название эксперимента — соль: оно перемешивает гостей заново для каждого теста.
